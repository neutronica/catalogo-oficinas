# Catálogo de Oficinas

Avaliação Prática 1 de Desenvolvimento Back-End I (Pós-graduação em Desenvolvimento Fullstack).

Aplicação Node.js + Express + Handlebars + Bootstrap para manter um catálogo de oficinas de treinamento em memória.

## Como executar

```
npm install
npm start
```

Acesse http://localhost:3000
